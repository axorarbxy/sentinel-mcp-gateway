# CyberEye frontend

The React operator dashboard lives here. For the full application setup, see the [root README](../README.md).

## Local development

```bash
npm install
npm start
```

The development server runs at `http://localhost:3000` and uses the local API at `http://localhost:8001` by default.

## Available scripts

- `npm start` starts the local development server.
- `npm test` runs the frontend test runner.
- `npm run build` creates a local optimized build in `build/`.
